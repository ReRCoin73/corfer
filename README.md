# CorFer 🎨

App de desenho e pintura para crianças — feito em HTML, CSS e JavaScript puro, sem dependências de build.

## Recursos

- **Modo Livre**: canvas em branco para desenhar do zero
- **Temas com desenhos prontos para colorir**: Animais, Veículos, Natureza e Formas
- **Ferramenta balde**: preenche áreas do desenho com um toque
- **4 estilos de traço**: caneta, giz de cera, pincel e marca-texto
- 16 cores, 3 tamanhos de pincel, borracha, desfazer, limpar tudo e salvar como PNG
- Interface com botões grandes, pensada para toque em tablets e celulares

## Como usar

Basta abrir o arquivo `index.html` em qualquer navegador — não precisa de instalação nem servidor.

## Estrutura

- `index.html` — aplicativo completo (HTML + CSS + JS em um único arquivo)
